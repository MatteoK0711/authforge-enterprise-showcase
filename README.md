AUTHFORGE NEO — PUBLIC LANDING PAGE

This package is intentionally separate from the paid AuthForge NEO source package.

WHAT IS PUBLIC:
- index.html
- landing.css
- flattened preview screenshots in /assets

WHAT IS NOT INCLUDED:
- authentication pages
- AuthForge NEO product CSS
- authentication JavaScript
- mock auth service
- downloadable product source

BEFORE DEPLOYING:
1. Open index.html.
2. Replace every occurrence of:
   REPLACE_GUMROAD_URL
   with your actual AuthForge NEO Gumroad product URL.
3. Upload ONLY this Public Landing folder to your static host.

Do not upload the paid AuthForge NEO product ZIP or its /pages, /css, /js source folders to the public landing host.
